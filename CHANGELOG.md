# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

## [1.1.0] - 2026-11-07

### Added
- Cart.sort_by_title() to sort DVDs alphabetically by title.
- Cart.sort_by_cost() to sort DVDs by ascending cost.
- search_by_category() for searching DVDs by category.

## [1.0.0] - 2026-11-07

### Added
- Cart.print_cart() for displaying cart contents.
- search_by_title() for searching DVDs by title.
- Use-case documentation.

### Fixed
- Reject adding a DVD when the cart already contains 20 DVDs (#6).
- Resolve conflicting cart success messages.
